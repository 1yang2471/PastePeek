# Code of Conduct

[简体中文](CODE_OF_CONDUCT.md) | English

## Our Commitment

The PastePeek community aims to provide a friendly, safe, and harassment-free environment for everyone, regardless of age, disability, ethnicity, gender, experience, nationality, appearance, race, religion, identity, or technical choices.

## Acceptable Behavior

- Respect different views and experiences; discuss issues with facts and reproducible evidence.
- Give constructive feedback and take responsibility for mistakes and their impact.
- Protect privacy; do not publish clipboard text, personal information, or security details.
- Focus on solutions that benefit the project and community.

## Unacceptable Behavior

- Harassment, insults, discrimination, threats, stalking, or personal attacks.
- Publishing another person's private information without permission.
- Posting sensitive clipboard content in Issues, Pull Requests, or other public channels.
- Repeatedly disrupting discussions, posting spam, or other unprofessional behavior.

## Enforcement

Maintainers are responsible for interpreting and enforcing this code. They may remove inappropriate content, restrict participation, or permanently ban participants for serious violations. Decisions should be proportionate to the nature and impact of the behavior.

## Scope

This code applies to the repository, Issues, Pull Requests, Release discussions, and other public spaces where someone represents the PastePeek community.

## Reporting

Report conduct concerns privately to the repository maintainers through GitHub. Report security vulnerabilities using [SECURITY.en.md](SECURITY.en.md). Maintainers will make a reasonable effort to handle reports confidentially and fairly.

This code is based on [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
