# Security Policy

[简体中文](SECURITY.md) | English

## Supported Versions

The current maintained line is `2.0.0-rc.x`. Unreleased development snapshots and older versions do not receive security fixes.

## Reporting a Vulnerability

Use the repository's private **Security > Report a vulnerability** channel. Do not paste clipboard content, personal information, or exploitable details into a public Issue.

Please include:

- PastePeek and Windows versions;
- reproducible steps and expected behavior;
- impact and affected scenarios;
- redacted logs or screenshots.

PastePeek does not proactively connect to the network. Report a security issue if a preview loads an external resource, changes the clipboard without an explicit action, records raw clipboard content, or executes clipboard content.
