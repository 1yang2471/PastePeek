# Support

[简体中文](SUPPORT.md) | English

## Usage Questions

Start with the system requirements, usage instructions, and compatibility limits in [README.en.md](README.en.md). If the issue is still reproducible, use the GitHub bug-report form.

Include the PastePeek version, Windows version, target application, reproduction steps, and expected result. Remove clipboard text, account details, file paths, and other personal information from screenshots and logs before sharing them.

## Feature Requests

Use the feature-request form. PastePeek remains local-only, keeps no clipboard history, and has no cloud service. Requests that require uploading clipboard content or adding a background cloud service are outside the product boundary.

## Security Issues

Do not create a public Issue. Follow [SECURITY.en.md](SECURITY.en.md) and use GitHub's private vulnerability-reporting channel.

This is a community-maintained project. No response time or commercial support commitment is provided.

For the Chinese support guide, see [SUPPORT.md](SUPPORT.md).
